# Repository Structure Guide

## Folder Organization

Each day (Day 1-30) has its own folder with the following structure:

```
day-XX/
├── README.md          # Main learning content and concepts
├── notes.md           # Key points and summary
├── commands.ps1       # Ready-to-use commands to practice
├── exercises.md       # Hands-on practice problems
└── solutions.ps1      # Example solutions to exercises
```

## File Descriptions

### README.md
- **Purpose**: Main learning material for the day
- **Content**:
  - Learning objectives
  - Key concepts with explanations
  - Real-world examples
  - Important notes and tips
  - Practice suggestions
- **How to use**: Read through this first to understand the concepts

### notes.md
- **Purpose**: Quick reference of important points
- **Content**:
  - Summary of main concepts
  - Key commands
  - Quick tips
  - Common gotchas
- **How to use**: Review before practice as a refresher

### commands.ps1
- **Purpose**: PowerShell script with all commands from the day
- **Content**:
  - Organized by topic
  - Fully functional examples
  - Comments explaining each section
  - Ready to copy and paste
- **How to use**: 
  - Open in PowerShell ISE or VS Code
  - Select and run individual lines or blocks
  - Modify to experiment

### exercises.md
- **Purpose**: Hands-on practice problems
- **Content**:
  - Multiple progressively challenging exercises
  - Clear objectives and tasks
  - Questions to think about
  - Challenge exercises
  - Reflection questions
- **How to use**:
  - Complete exercises in order
  - Try without looking at solutions first
  - Use solutions only to verify

### solutions.ps1
- **Purpose**: Reference implementations
- **Content**:
  - Solution code for each exercise
  - Explanatory comments
  - Alternative approaches where applicable
- **How to use**:
  - After completing exercises
  - To understand different approaches
  - As a learning reference

## Recommended Daily Workflow

```
1. Start with README.md (20-30 minutes)
   └─ Read concepts, examples, and tips

2. Review notes.md (5 minutes)
   └─ Quick overview of key points

3. Practice with commands.ps1 (15 minutes)
   └─ Run examples and experiment

4. Complete exercises.md (15-20 minutes)
   └─ Work through all exercises

5. Check solutions.ps1 (10 minutes)
   └─ Verify your approach
```

## Progression Through the Course

### Week 1: Foundations (Days 1-7)
- Basic PowerShell concepts
- Navigation and file operations
- Command discovery
- Help system mastery

### Week 2: Variables and Basics (Days 8-14)
- Data types and variables
- String manipulation
- Arrays and collections
- Basic scripting

### Week 3: Logic and Control (Days 15-21)
- Conditional statements
- Loops and iteration
- Functions and parameters
- Error handling

### Week 4: Advanced Concepts (Days 22-28)
- Objects and properties
- Modules and scripting
- System administration tasks
- Real-world applications

### Week 5: Projects (Days 29-30)
- Consolidation of learning
- Complex automation projects
- Advanced techniques

## Tips for Using This Repository

1. **Go sequentially**: Don't skip days; concepts build on each other
2. **Read everything**: Don't just skim; understanding matters
3. **Type the code**: Don't copy-paste; muscle memory is important
4. **Experiment**: Modify examples to see what happens
5. **Take notes**: Write down important concepts
6. **Ask questions**: Use PowerShell's help system extensively
7. **Review regularly**: Revisit previous days when confused
8. **Build projects**: Apply learning to real problems
