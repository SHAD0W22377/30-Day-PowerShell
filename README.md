# 30 Days of PowerShell

A comprehensive, structured 30-day learning plan to master PowerShell from beginner to intermediate level.

## 📚 Overview

This repository contains a complete 30-day curriculum designed to take you from PowerShell basics to practical scripting and system administration. Each day includes:

- **Learning objectives** - What you'll learn
- **Key concepts** - Important topics and cmdlets
- **Hands-on examples** - Real-world code snippets
- **Practice exercises** - Reinforce what you've learned
- **Solutions** - Reference implementations

## ⏱️ Time Commitment

Each day's content should take approximately **30-60 minutes** to complete, including:
- Reading and understanding concepts (20 minutes)
- Practicing commands (20 minutes)
- Completing exercises (20 minutes)

## 📋 Curriculum Overview

### Phase 1: Foundations (Days 1-5)
- Introduction to PowerShell
- Cmdlets and Aliases
- Getting Help
- Files and Directories
- Providers and Drives

### Phase 2: Variables and Scripting (Days 6-10)
- Variables and Data Types
- String Manipulation
- Arrays and Hashtables
- Piping and Output Formatting
- Simple Scripts

### Phase 3: Logic and Loops (Days 11-15)
- Conditional Statements
- Looping Structures
- Functions
- Error Handling
- Script Parameters

### Phase 4: Advanced Topics (Days 16-20)
- Objects and Properties
- Modules
- PowerShell Remoting
- Registry Manipulation
- Best Practices

### Phase 5: System Administration (Days 21-25)
- Managing Processes and Services
- Network Cmdlets
- Scheduled Tasks
- Event Logs
- Inventory Scripts

### Phase 6: Projects and Advanced (Days 26-30)
- Automation Projects
- PowerShell Profiles
- Debugging
- Security
- Advanced Concepts

## 🚀 Getting Started

1. **Start with Day 1**: Navigate to the `day-01` folder
2. **Read the concepts**: Open `README.md` in each day's folder
3. **Follow the examples**: Run commands from `commands.ps1`
4. **Complete exercises**: Work through `exercises.md`
5. **Check solutions**: Review `solutions.ps1` when needed

## 💡 Tips for Success

1. **Practice consistently** - Don't skip days; learning compounds over time
2. **Type the code** - Don't copy-paste; typing helps muscle memory
3. **Experiment** - Modify examples to see what happens
4. **Ask questions** - Use `Get-Help` extensively
5. **Build on knowledge** - Each concept builds on previous lessons
6. **Take notes** - Write down important commands and concepts
